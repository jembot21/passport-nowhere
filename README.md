# Passport Nowhere — make.fun bounty entry

The Republic of Velmaris is an invented maritime republic of tidal islands, lighthouse keepers and ferries. This deterministic Python program uses Pillow to draw an open passport spread with its data page, ICAO-style machine-readable zone, and stamped visa page.

Run with `python3 main.py`. It writes `/output/entry.png`; the only dependency is Pillow, and the program uses no network.
